# reactive-skills-axi

This package is an alias for [`@reactive-skills/axi`](https://www.npmjs.com/package/@reactive-skills/axi), the Reactive Skills command-line interface.
It contains no code of its own: its `reactive-skills-axi` command runs the pinned `@reactive-skills/axi` release.

Install the official package directly:

```sh
npm install -g @reactive-skills/axi
```

Source: https://github.com/Reactive-Skills/reactive-skills
